# Agent Note: 工作流命令、生命周期与证据链接保持一致

Status: implemented

## Problem

用户在评审最终工作流后明确要求修复问题。修复前 `docs/ai-workflow.md` 使用不存在的 `--since` 参数，方案模板允许与正文和校验不一致的 `Status: archived`，校验脚本不支持被否决方案的 `rejected` 状态。链接检查仅覆盖三个入口文档，未覆盖 Note 和证据 README；S 级视觉调整仍默认使用九段证据模板。

修改前运行 `python3 scripts/check-workflow.py`，结果为 0 FAIL、7 WARN。七条均为历史证据目录命名或缺 README，不作为本轮新增问题。

## Decision

- [AI 执行手册 v1.1](../../../../docs/ai-workflow.md) 与 AGENTS、流程事实文档统一使用 `--commits N`，它仅限制提交信息检查数量，其余检查仍是全量。
- Note 生命周期与校验采用同一规则：proposed 对应 proposed；implemented 对应 implemented；archived 保留 implemented 并添加 Archived 日期；rejected 使用 `Status: rejected — 原因` 并保留提案结构。未知生命周期、状态与目录不符及缺少否决原因均产生 FAIL。
- [自检脚本](../../../../scripts/check-workflow.py) 检查入口文档、Note Markdown 和所有层级证据 README 的本地文件与图片目标，忽略围栏/行内代码及外部 URI；编码路径、标题、括号和引用式定义均参与扫描，锚点仅移除而不校验。
- 源码 `文件:行号[:列号]` 引用优先检查完整文件名，仅在目标不存在时剥离数字后缀并检查源文件。电话等数字 URI 单独识别，缺失的源码文件仍报 FAIL。
- 历史归档 Note 的一条跨生命周期引用修正并追加维护说明；旧临时 APK 链接改为历史路径并明确产物缺失，原日志、摘要和截图保留。用户已有 iOS 提案及证据独立于本轮修改。
- S 级纯视觉/文案的证据可合并为三段，保留 V3 截图、原始输出、失败记录、复跑信息、设计依据与交付状态。涉及行为、契约或重要取舍仍采用完整流程；M/L 保留九段模板。
- [定向测试](../../../../scripts/test_check_workflow.py) 使用 Python 标准库和临时目录，验证生命周期、链接扫描与退出码，没有新增依赖。

## Alternatives considered

- 仅修改文档：能修复参数示例，无法发现拒绝记录或证据内部的断链。
- 把 archived 设为独立 Status：违反既有归档规则并增加历史迁移成本；继续使用 implemented 加 Archived 日期。
- 为历史断链降级或自动忽略：会保留已经发现的证据链缺口；修复可确定的引用，缺失事实则明确记录。
- 引入完整 Markdown 解析依赖：当前需求是本地目标存在性检查，使用标准库实现并用边界夹具防止误报，避免改变依赖和构建流程。
- 删除 S 级证据要求：会失去视觉变更的可复核性；仅精简模板结构，不降低验证要求。

## Validation

最高 V2，21 个 Python 定向用例通过，覆盖合法/非法状态、否决原因、归档日期、未知生命周期、Note 和嵌套 README 的链接/图片、代码示例、URI、编码与标题、括号、引用式定义、源码行列号及正常/strict 退出码。修改前 17 个用例中的 10 项失败作为回归依据保留，不计通过。

实际执行 `python3 scripts/check-workflow.py --commits 20`，全量自检 0 FAIL、7 WARN；七条均与原基线一致，分别为六份历史证据缺 README 和一处旧命名。CLI 帮助和 `git diff --check` 已核对。方案快照、原始失败/通过输出、环境与复跑信息见 [证据包](../../../../docs/ux-evidence/2026-11-04-workflow-consistency/README.md)。

未验证 Android 产品行为、真机、截图内容、历史源码行号语义和发布产物；自检通过不代表这些项目已经验证。

## Consequences

工作流可按仓库内模板和命令执行，拒绝记录及证据内的断链可被发现。链接扫描范围扩大，会要求后续任务及时维护迁移后的引用；它仍是结构和目标存在性检查，README 内容完整性、截图与断言正确性需独立核对。旧 APK 已缺失的事实明确保留，没有重新构建替代历史证据。S 级减少重复标题，但遇到重要取舍仍需完整方案和证据。

七条历史 WARN 保留，没有补造旧证据的验证事实。本轮只修改流程、校验及引用维护，未提交、未推送、未发布。
