# 工作流模板

模板复制到目标位置后再填写；文件名使用日期和英文 kebab 主题，状态与目录同步。

日常任务默认用 [精简证据](evidence-small.md)，没有独立输出的小任务可在回复或已有 Note 记录。[完整证据](evidence-full.md) 用于多环境、复杂迁移、发布或事故；任务规模不决定模板。重要决定才用 Note，普通任务说明可压成一两句；验证方式按验收问题选，不追求 V 编号。
