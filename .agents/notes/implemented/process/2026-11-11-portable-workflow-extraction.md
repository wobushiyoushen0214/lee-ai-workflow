# Agent Note: 将 momofish-android 工作流提取为独立试用包

Status: implemented

## Problem

用户要把 momofish-android 的完整工作流交给别人试用。规则分散于 AI 入口、完整执行手册、项目流程事实、决策留痕技能与脚本；原版路径、Android 包名和发布后缀绑定原项目，直接复制不能完整接入别人的项目。

## Decision

在同级独立目录交付可移植试用包，完整保留手册 G0–G9、异常、协作、交接、模板、DoD 和附录。附录 A 与 workflow.md 采用项目适配表；日常自检由 Python 标准库实现，JSON 指定项目内目录、入口文档和发布记录后缀，commits=0 不读 Git，空发布历史不产生虚构版本记录。单 Agent 默认；当前用户指令及已有授权优先，授权范围内先写方案再继续实现。

原版 AGENTS、两份工作流、自检和回归、两份 Android 辅助脚本及历史工作流修复记录完整保存为 txt 快照；来源清单记录 SHA-256。完整随包技能保留全部 references、脚本及 package.json，并对齐 Validation、rejected 的 Acceptance criteria 和归档规则；基础校验不要求全局安装或 tsx。

接入工具先预览，--apply 写入前整批检测同名内容与入口标记冲突、项目外符号链接及路径类型；保留已有 AGENTS 原文并追加独立入口。接入包括规则、模板、技能、配置、校验、回归和原版参考，排除本轮 Note、证据和包的根 README。重复接入相同内容无操作；既有内容不同则拒绝并要求手工合并，不覆盖业务。

## Alternatives considered

- 仅复制两份 Markdown：缺技能、模板和校验依赖，不能完成独立试用。
- 复制全部 Android 工程：混入业务、签名和大型产物，偏离工作流提取范围。
- 覆盖原文以去除绑定：损失真实流程与历史取舍；保留完整快照，再提供通用执行版本。
- 强制全局安装技能或新增框架依赖：影响别人环境；技能随项目携带，基础流程只用 Python。
- 把带根目录链接的 AGENTS 入口作为 Markdown 模板：会在模板目录产生断链；使用 txt 原文模板，追加到项目根 AGENTS 后再检查其真实链接。
- 不接入 reference：手册中的来源链接无法访问；一并接入轻量完整原文，仅本轮证据和记录不进入目标项目。

## Validation

V2，33 个定向用例通过。首次失败的 3 个用例发现接入链接问题，修复后通过；失败工具输出摘录保留且不计通过。证据和精确复跑命令见 [验证记录](../../../../docs/ux-evidence/2026-11-11-workflow-extraction/README.md)。临时项目验证换 cwd、中文/空格路径、已有 AGENTS 保留、重复接入、冲突与符号链接拒绝、配置错误、发布记录和四态模板。

来源文件与原文快照按提取哈希逐项核对。全包链接、自检和封包在收尾完成；SHA256SUMS 与 ZIP 侧边摘要供传输核对。未验证别人真实业务项目、产品构建、设备、截图、发布或保留的 TypeScript 可选校验器。

## Consequences

接手者可凭完整规则、模板和原版背景在独立目录试用，无原机运行路径、凭据或全局技能依赖。原仓库保留用户已有工作；交付是本地目录和 ZIP，未提交、推送或发布。

各项目仍须填写实际构建、测试、隔离与发布适配；结构自检不能证明截图、断言和摘要正确。相同文件可重复接入，但修改过的接入内容需要手工合并。原始辅助工具依赖 Android 宿主和历史资产，只供参考，不被复制为通用执行脚本。
